# 我看得见也摸得到

我看得见你的屏幕，也摸得到你的鼠标和键盘。

先看，再动。每一步都在你眼前，按 Esc 我就停。

## 为什么是「看」和「摸」

桌面上的事，失败通常不是点不中，而是**没看见就动手**：窗口还没到前台、弹窗还没出来、坐标是上一帧的。所以这里的第一件事永远是截图：真实桌面、逐显示器 DPI 感知、一个图像像素就是一个物理屏幕像素。坐标尺直接标屏幕坐标，读位置不用数像素。

看见了，才轮到手：移动、点击、拖拽、滚轮、输入、按键、聚焦窗口。窗口没有可用的 UIA 树时（canvas、绘图区、什么也不发的 Electron 窗口），就回到截图；有控件树时，`controls` 比截图便宜得多，点 `target: 3` 就是那个控件矩形的中心，而且索引在点击前会重新校验——树变了就报错，不会点到顶替上来的邻居。

截图和点击之间最容易出错的是坐标换算：窗口/区域截图有原点，模型看到的图还可能被缩小。所以工具接受 `imageX/imageY`——按图上的像素点，插件用最近一帧的原点和比例换成物理坐标；只有在你看到的图和插件交付的图尺寸不同时，才需要再带上 `imageWidth/imageHeight`。

## 一次调用做一串，最后只看一眼

逐步调用 `desktop_control` 的代价不是点击，是每一动作一次模型往返和一张截图。`desktop_sequence` 把一串动作压进一次调用：

- 步骤按顺序跑，默认第一步失败就停，不会出现「聚焦被拒绝，后面还继续往别的窗口打字」。
- 整批共用一个取消令牌和一圈提示环，Esc 停的是整批，不是碰巧在跑的那一步。
- 最后默认只截当前前台窗口一帧，不是整块桌面；和上一帧像素一致时不再附带图片。
- `dryRun: true` 只校验和列出计划，不碰桌面。

## 你能看见我在做什么

操作开始时，屏幕边缘亮起一圈光。这不是装饰：它同时注册 Esc 热键，按下去会在两步之间停下。提示环默认在最后一个动作后停留 3 秒，够你看清是谁在动。

屏幕顶部还会出现一张提示卡：提示框旁边挂着一个气泡，写着这一步在做什么；主提示是「我正在干活 [Esc] 停下」。气泡会跟着动作和序列步骤更新，看起来就像提示框在说话，所以你不必猜我正在进行到哪一步。

提示环不写光标、不装输入钩子——它不会让你自己的鼠标变卡。

## 有些键，必须先问过你

`win+r`、`ctrl+shift+esc`、`alt+f4`、`shift+delete`，以及把焦点切到 UAC 窗口，内置判为高风险。即使调用方把它们标成 low，守卫也会拒绝；只有带 `confirm: true` 才会执行，并在结果里留下「危险操作已确认」的注记。

批量里一旦出现这样的步骤，整批的风险自动升到 high，同样要 `confirm: true`。

这不能替代你的判断，但能保证：**危险操作不会因为一句“风险很低”就溜过去。**

## 截图放哪

默认放系统临时目录，工程目录保持干净。想留在工作区，就在设置里切到「当前工程目录」；插件会在 `.see-touch/` 里放一行 `*` 的 `.gitignore`，git 不会把它当未跟踪文件。

无论放哪，都按三个维度裁剪最旧的帧：张数、天数、目录总容量。聊天里已经发出的图片是附件存储里的副本，不受清理影响。

## 引擎

默认 `auto`：有 PowerShell 7（`pwsh`）就用它——启动更快、默认 UTF-8；没有就退回每台 Windows 都有的 Windows PowerShell 5.1。设置成 `pwsh` 但机器没装时，插件不会消失，第一次调用会明确告诉你去装或改回 `auto`。

## 已知边界

- 仅 Windows；其他系统上工具调用会直接说明，不给 `ENOENT`。
- 需要接受图片输入的模型。
- UAC 安全桌面无法截图或注入。
- 输入送给真实前台窗口，操作前后各看一眼仍是最可靠的习惯。
- 文字以一次粘贴送入，不是逐字按键。

## 停用

设置 → 插件 里关掉「我看得见也摸得到」，或把 profile 里的 `include:see-touch` 设为 `enabled: false`。关掉后三个工具一起消失，不会留下后台进程。

完整配置表和安全说明见 [README.md](README.md)。
